# Experiments

No quantitative result is designated as a release-ready public result in this
version of the repository.

The private research workspace contained exploratory runs, failed runs, raw
model responses, intermediate analyses, and draft paper figures. Those files
were retained in the local pre-release archive and excluded here because their
provenance, interpretation, and reproduction requirements have not yet been
reviewed to a public-release standard.

Future public results should include the exact configuration, input provenance,
environment, generation or analysis command, and a machine-readable summary.
Any number cited in the main README should point to those materials.
